# Система учёта оборудования отдела информационных технологий

Desktop-приложение для автоматизации учёта, хранения и отслеживания околокомпьютерного оборудования предприятия.

## О проекте

Проект разработан на основе задач, выявленных в ходе прохождения производственной практики на предприятии.
В процессе практики была изучена существующая организация учёта оборудования, рассмотрены особенности его распределения по подразделениям и помещениям. На основе полученного опыта была разработана информационная система, направленная на упрощение и автоматизацию данного процесса.

Приложение предназначено для централизованного ведения учёта околокомпьютерной техники, хранения сведений об оборудовании и контроля его текущего местоположения.

## Функциональные возможности

- Регистрация и учёт оборудования.
- Управление информацией об оборудовании.
- Учёт подразделений предприятия.
- Управление помещениями и их привязкой к подразделениям.
- Отслеживание местоположения оборудования.
- Поиск и фильтрация записей.
- Редактирование и удаление данных.
- Формирование отчётной документации.
